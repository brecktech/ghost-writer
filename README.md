# GHOST WRITER

A multiplayer party game. One person runs the server, everyone else joins from their phone.

## Setup (one time)

1. Make sure Node.js is installed: https://nodejs.org
2. Open a terminal/command prompt in this folder
3. Run: `npm install`

## Start the game

1. Run: `npm start`
2. The terminal will show a URL like `http://192.168.1.42:8080`
3. Everyone on the same WiFi opens that URL on their phone
4. One person creates a lobby, shares the 6-digit code, others join

## How to play

- The prompter writes a prompt like "Stuff... you'd never say to your boss"
- Everyone else submits a secret response
- The prompter picks their favorite (+1 point to the writer)
- Players take turns guessing who wrote each response (+1 for correct guesses)
- First to the target score wins!
